ANDROID · WORKSPACE + ASSISTANT

SUMMON IT WITH
YOUR OWN
NAME.

Install Liquid Core as a PWA. Then bind three triggers: a custom wake word (“hey NOVA”), a long-press on the power key, or the Android accessibility shortcut. Any of them raises the glass orb over whatever you're doing — the model answers in text and speech, fully offline.

  1. Install. Chrome on Android → menu → Add to Home screen. The engine weights are cached by the service worker.
  2. Name it. Set your prefix below. The listening loop stays tiny — keyword spotting runs on-device.
  3. Bind the hardware. Settings → Accessibility → Quick settings / Shortcut → point it at Liquid Core; or map a long-press-power gesture with a shell app such as Pointer+ / Tasker (am start -n …/MainActivity --es cmd wake).
  4. Go dark. Enable airplane mode. Everything still works. That's the point.
